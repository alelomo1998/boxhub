# M4 Tracking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.
> **This project's pace (CLAUDE.md):** DEFAULT is inline execution by the main thread — write files, run tests+build, commit in batches. Spawn an agent ONLY for genuinely parallel or high-risk work. The self-log tenancy (T3) and leaderboard ordering (T4) are the care-points here.

**Goal:** Athletes log WOD scores against published slots and named-lift maxes, and view history, PRs, per-movement progression, benchmark history, and a per-session leaderboard.

**Architecture:** New backend package `com.boxhub.performance` (Flyway V6, 2 tables — both `@TenantId`). Scores attach to `program_slot`; benchmark PRs are derived by joining scores to slots whose WOD has a `benchmark_template_id`; a separate `lift_entry` table holds named maxes with auto-PR. Frontend extends the athlete WOD board with score logging + leaderboard peek and adds a "My progress" page (history/PRs/inline-SVG chart) replacing the PR placeholder.

**Tech Stack:** Spring Boot 3.4 / Java 21 / Hibernate 6 `@TenantId` / Postgres 16 / Flyway. Angular 19 standalone + signals, `bh-*` components, SCSS tokens, inline SVG. Testcontainers, Karma, Playwright.

## Global Constraints

- **Build env:** `export JAVA_HOME=/opt/homebrew/opt/openjdk@21` for every backend `mvn`.
- **Flyway only for schema.** Next migration is **V6**. Never edit an applied migration.
- **Tenancy:** resolve tenant ONLY from `TenantContext`. **Self-log:** `membership_id` comes from the caller's JWT via `memberships.findByUserIdAndBoxId(TenantContext.userId(), TenantContext.requireBoxId())` — NEVER a request param. Every box endpoint gets happy + auth-denied + cross-tenant-denied tests; plus athlete-A-cannot-touch-athlete-B tests on the score paths.
- **Tenant-filter idiom:** foreign id looks absent under `@TenantId` → `findById(...).orElseThrow(NoSuchElementException::new)` yields the cross-tenant 404.
- **Roles:** any ACTIVE box member may self-log and read. No coach/roster write surface (that's M6).

```sql
-- V6__tracking.sql
create table wod_score (
    id            uuid primary key default gen_random_uuid(),
    box_id        uuid not null references boxes(id),
    slot_id       uuid not null references program_slot(id),
    membership_id uuid not null references memberships(id) on delete cascade,
    rx            boolean not null default true,
    time_seconds  int,
    rounds        int,
    reps          int,
    load          numeric(7,2),
    finished      boolean not null default true,
    notes         text,
    private       boolean not null default false,
    created_at    timestamptz not null default now(),
    updated_at    timestamptz not null default now(),
    unique (box_id, slot_id, membership_id)
);
create index idx_score_slot on wod_score (box_id, slot_id);

create table lift_entry (
    id            uuid primary key default gen_random_uuid(),
    box_id        uuid not null references boxes(id),
    membership_id uuid not null references memberships(id) on delete cascade,
    movement_id   uuid not null references movement(id),
    load          numeric(7,2) not null,
    reps          int not null default 1,
    performed_on  date not null,
    notes         text,
    is_pr         boolean not null default false,
    created_at    timestamptz not null default now()
);
create index idx_lift_prog on lift_entry (box_id, membership_id, movement_id, performed_on);
```

- `Leaderboard.rank(List<WodScore> scores, String scoreType)` — pure function, returns ordered `List<WodScore>`:
  - filter out `private` scores.
  - RX (`rx=true`) block first, scaled block second; within each block order by:
    - `TIME`: finished first ordered by `timeSeconds` asc; then unfinished ordered by `reps` desc (null reps last).

    - `NONE`: keep insertion order (completion list).
